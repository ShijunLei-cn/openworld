## 生成提示词

地图角色：以 Claude 三视图为人物身份，鲸鱼娘图为风格参考；保留橙色长发、橙花与黑色缎带、琥珀眼、白色荷叶边裙、黑色腰身及橙色点缀；四行依次正、左、背、右，每行四个走路姿态，Q 版像素风、透明背景。

v2 在 v1 基础上使用用户提供的鲸鱼娘图强化阶梯描边、像素块、平涂与比例，同时保留 Claude 发色、花饰和服装。

立绘：以 Claude 三视图及上述地图角色为角色身份，参考鲸鱼娘中性立绘的构图与 Q 版风格；生成透明背景半身对话立绘，保留橙花、缎带、白色荷叶边和黑橙色服装。
