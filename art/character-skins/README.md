# Character skin artwork drafts

This directory contains the current local artwork drafts for the whale girl, Claude girl, and GPT dragon girl. The original folder structure, source images, animation metadata, previews, and notes are preserved. These drafts are not connected to the game.

The individual folders document the references and generation process. Some reference-image distribution terms have not been established; inclusion here does not establish a CC0 dedication for these drafts. Review their provenance and applicable permissions before including them in a game release.

The selected whale-girl design is `鲸鱼娘/whale-girl-source-4x4-v1.png`; the user prefers displaying it by scaling the original image. Other files are retained as part of the complete source folder.
